SECTION: 7Application Fee
LOCATION: heading: 7Application Fee / passage 1

1. Application Fee: KRW 80,000(per Admission Track)
2. Payment Method
- A. The Application Fee must be paid using the online application program.
- B. If the Application Fee is not paid within the Application Period, the application will be automatically canceled.
- C. An application number will be issued upon payment of the application fee, after which no changes can be made to the application.
3. Once the application fee has been paid, the application cannot be canceled, and the application fee is nonrefundable.
